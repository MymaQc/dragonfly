# Evidence for the fix branches of this fork

Each folder holds the reproduction of one bug in Dragonfly, run on unmodified upstream `master` (106fdc28) and on the
fix branch of the same name: screenshots and GIFs taken by a Bedrock client connected to a real Dragonfly server, or
the output of a standalone reproduction program (`before.txt`, `after.txt`). Each folder's `README.md` gives the exact
steps, versions and what every file shows.

This branch only stores evidence; it is not meant to be merged.
